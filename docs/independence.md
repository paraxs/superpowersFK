# Independence Boundary

This codebase uses its own name, repository metadata, documentation, workflow policy, tests, and release direction.

It does not require an upstream marketplace, community service, telemetry endpoint, homepage, author profile, or runtime dependency.

The repository is currently hosted as a GitHub fork. GitHub will continue to display the fork-network relationship until the code is copied into a new standalone repository. That hosting relationship cannot be removed by editing files.

The `LICENSE` file retains the copyright and MIT license notice required by the license under which substantial portions were received. Removing that notice would violate the license and is not part of the independence work.
