# Quality Scorecard

The current FK branch targets a minimum score of 9/10 in every operational category.

| Category | Target | Repository control |
|---|---:|---|
| Method | 9+ | Risk-tier routing and explicit escalation |
| QA | 9+ | Risk-based tests, verification, diff checks, CI |
| Codex integration | 9+ | Native manifest, no hook discovery surface, runtime notes |
| Efficiency | 9+ | No universal planning or brainstorming |
| Preservation | 9+ | Global no-regression and focused-change rules |
| Multi-agent safety | 9+ | Entry gates and circuit breakers |
| Cost control | 9+ | Bounded reviews and honest model inheritance |
| Privacy | 9+ | No default telemetry or remote helpers |
| Maintainability | 9+ | Smaller skills and policy regression tests |
| Transparency | 9+ | Evidence and remaining-risk reporting |

A score of 10 requires repeated real Codex acceptance runs, not documentation alone.
